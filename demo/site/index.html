Binance MCP Cloud is an unofficial, hosted demo of the Binance MCP server. People and AI agents get the same 19 tools: live prices, order books, trades, candles, top movers and new listings. There is also a paper-trading account that fills against the real order book, price alerts that are checked every minute, and BNB Chain wallet balances. You can use them from the browser console, a REST API or a single MCP URL.

Real market data, simulated money

Sign in with MetaMask, Rabby, Coinbase Wallet, Phantom or any EIP-6963 or Solana wallet. Every price comes from the live Binance book. No exchange account or API secret is needed, and no real order is ever placed.

◎

Market explorer

Search every trading Binance spot pair. You get the 24-hour ticker, a candlestick chart from 1 minute to 1 month, the live order book and the latest trades.

⇄

Paper trading

Start with 10,000 USDT. Market orders walk the real order book level by level, so you see true slippage. Limit orders rest until the market crosses them. Fees are 0.1%, as on Binance.

◔

Price alerts

Set up to 50 alerts above or below any price. A cron job checks them against live prices every minute and records when and where each one fired.

⚖

Fill simulator

Before you trade, preview the average price, worst price, slippage and price impact for any size against the top 1,000 levels of the book.

⌁

MCP endpoint

Point Claude, Cursor or any MCP client at /mcp with an API key. All 19 tools are listed with JSON Schemas, so the agent knows exactly what each one needs.

⬡

Listings & BNB Chain

Follow Binance's new-listing announcements. You can also read BNB, USDT, USDC, FDUSD, BTCB and ETH balances on BNB Smart Chain for any address, priced in USD.

From wallet to first fill in four steps

Every step is a real call against live market data. Nothing costs gas, and no funds move.

Sign in

Connect a wallet and sign one message (SIWE or SIWS). You don't pay gas or create an account, and your session lasts 30 days.

Pick a pair

Open any spot pair, such as BTCUSDT or SOLUSDT, to see its chart, book and trades.

Preview the fill

Enter a size to see the average price and slippage the live book would give you.

Trade on paper

Place a market or limit order. Your balances, equity and P&L update from live prices.

Built for agents first

The console calls the same routes your agents do. Create a key under API keys and call these routes:

  • GET /api/tools lists every tool with its JSON Schema
  • POST /api/run/:tool runs one tool with a JSON body
  • GET /api/live returns the public market board shown above
  • POST /mcp is a stateless MCP endpoint over Streamable HTTP (JSON-RPC, batches allowed)
# Simulate a 0.5 BTC market buy against the live book
curl -s -X POST https://binance-mcp.ninabrekkerese.workers.dev/api/run/simulate_market_order \
  -H "authorization: Bearer $BMCP_KEY" \
  -H "content-type: application/json" \
  -d '{"symbol":"BTCUSDT","side":"buy","quantity":0.5}'

# mcp.json
{
  "mcpServers": {
    "binance": {
      "type": "http",
      "url": "https://binance-mcp.ninabrekkerese.workers.dev/mcp",
      "headers": { "Authorization": "Bearer sk_bmcp_…" }
    }
  }
}
